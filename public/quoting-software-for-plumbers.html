Before you send a price

Catch the work that is easy to leave out.

Check the installation scope

List the rooms, systems or fittings involved. Include removal, isolation, alterations, installation and the agreed checks on completion.

Allow for the small parts

Review pipework, valves, connectors, traps, sealants and waste removal. Check whether the customer-supplied items include the necessary fittings.

Price access and repeat visits

Consider awkward access, draining down, refilling, testing and working around other trades. Record assumptions about existing pipework and allow for uncertainty appropriately.

Questions before you start

How do I handle customer-supplied materials?

Make it clear which items the customer supplies and which you supply. Include your installation labour and any additional parts, check compatibility and delivery assumptions, and review the scope before you approve the quote.

Can it assess hidden pipework problems?

No. Describe what you have inspected, state assumptions about inaccessible areas and review an appropriate contingency. If the scope changes once work starts, agree the additional work and price with the customer.
